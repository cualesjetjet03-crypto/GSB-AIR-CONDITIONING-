🔧 Common Issues & Solutions

Issue: RSVP Form Not Working

Symptoms: Form submits but no success message

Solutions:
  • Check PHP is installed: php -v
  • Verify data/ directory exists and is writable
  • Check browser console for errors (F12)
  • Ensure submit_rsvp.php is in root directory

Issue: Baby Photo Not Showing

Solutions:
  • Verify filename is exactly baby-photo.jpg or baby-photo.png
  • Check file is in assets/ directory
  • Clear browser cache (Ctrl+F5)
  • Try different image format

Issue: Audio Not Playing

Solutions:
  • Verify file is named music.mp3 in assets/
  • Check file format is MP3
  • Try clicking after page loads (browsers block autoplay)
  • Test in different browser
